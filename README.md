\# Mini Music Library



A small FastAPI application used as a demonstration project

for testing an automated DevSecOps security pipeline.



\## Features



\- View all songs

\- View a song by ID

\- Health check endpoint



\## Technology



\- Python

\- FastAPI

\- Uvicorn



\## Purpose



This repository is used to demonstrate how the DevSecOps

security pipeline detects security issues before code can

be merged into the main branch.
